# ProjectElec

ระบบจัดทำเอกสารรายวิชาโครงงานผ่านโทรศัพท์มือถือ ตาม "คู่มือการจัดทำรายงานผลรายวิชาโครงงาน" วิทยาลัยเทคนิคสมุทรปราการ ภาคเรียนที่ 2/2569
นักเรียนที่ไม่มีคอมพิวเตอร์ทำ คพ.01 รายงาน 5 บท และคำร้อง คพ. ได้ครบจากมือถือ แล้วดาวน์โหลดเป็น PDF หรือ Word ที่จัดหน้าเสร็จแล้ว

## สิ่งที่มีในเวอร์ชันนี้ (P0)

- เข้าสู่ระบบด้วย **รหัสห้อง + รหัสนักศึกษา + รหัสผ่าน** (ไม่ต้องใช้บัญชี Google) ครูรีเซ็ตรหัสผ่านให้ได้
- ครูสร้างห้อง (ปวช./ปวส.) ได้รหัสห้อง 6 ตัว เห็นทุกกลุ่ม ความคืบหน้า และเปิดดูเอกสาร A4 ของแต่ละกลุ่ม
- กลุ่มโครงงาน: หัวหน้าสร้าง เพื่อนเข้าร่วมด้วยรหัสกลุ่ม จำกัด ปวช. ≤ 3 คน / ปวส. ≤ 2 คน (คู่มือหน้า 4) ครูปรับข้อยกเว้นได้
- **คพ.01 แบบตอบคำถามทีละข้อ** 22 คำถาม ตามลำดับและคำแนะนำในวงเล็บของแบบฟอร์ม (คู่มือหน้า 14–19) พร้อมตัวอย่างจากคู่มือ
- ตัวแก้ไขละเอียดของทุกส่วนรายงาน (บทที่ 1–5 บทคัดย่อ ภาคผนวก) จากเวอร์ชันแรก
- บันทึกอัตโนมัติ: เก็บในเครื่องก่อนทุกครั้ง แล้วส่งขึ้นเซิร์ฟเวอร์เมื่อออนไลน์ เน็ตหลุดหรือปิดเบราว์เซอร์ข้อมูลไม่หาย
- สมาชิกหลายคนแก้พร้อมกันได้ (รวมการแก้ไขรายช่อง) และมีประวัติการแก้ไขย้อนกลับได้
- ถ่ายรูปจากกล้องหรือเลือกจากแกลเลอรี ย่อขนาดบนมือถือก่อนส่ง หมุนภาพได้
- **เซิร์ฟเวอร์สร้าง PDF และ DOCX** ด้วยฟอนต์ TH SarabunPSK สารบัญมีเลขหน้าจริงใน PDF และดูหน้า A4 เป็นภาพบนมือถือได้
- นับจำนวนหน้าบทที่ 1–5 จาก PDF จริง เทียบเกณฑ์ไม่น้อยกว่า 30 หน้า (คู่มือหน้า 75)
- ติดตั้งเป็นแอป (PWA) ได้

## เพิ่มใน P1

- **ส่งงานให้ครูตรวจ** 5 ขั้นตามปฏิทิน 18 สัปดาห์: คพ.01 · 50% (บทที่ 1–3) · 70% (บทที่ 4–5) · 90% ส่งเล่มตรวจ · ฉบับแก้ไขสมบูรณ์ ครูรับรองหรือส่งกลับพร้อมข้อความ (ยังต้องยื่นคำร้องที่ลงชื่อจริงตามคู่มือ)
- **ความเห็นของครูรายส่วน** (คพ.01 บทที่ 1–5 ภาคผนวก) แสดงเป็นแถบบนหน้าที่เกี่ยวข้อง นักเรียนกด "แก้แล้ว" ได้
- **แบบ คพ.03 / คพ.05 ครั้งที่ 1–2 (พร้อมเอกสารแนบประเมินรายข้อ) / คพ.07 กรอกบนมือถือ** แล้วพิมพ์เป็น PDF/Word ตามแบบในคู่มือ ช่องลงชื่อและความเห็นผู้บริหารคงไว้ให้ลงนามด้วยมือ
- ชื่อคณะกรรมการ 3 คน (ค่าของห้องและรายกลุ่ม) และชื่อผู้บริหาร ตั้งได้ในหน้าห้อง
- **บันทึกข้อมูลจริงจากมือถือ**: คะแนนผู้เชี่ยวชาญ / ความพึงพอใจ แตะ 1–5 ทีละคน, IOC (+1/0/−1), ผลทดลองรายครั้งแบบผ่าน/ไม่ผ่าน หรือค่าที่วัดได้พร้อมหน่วย เป้าหมาย และค่าคลาดเคลื่อน (คำนวณ x̄ S.D. ต่ำสุด สูงสุด ร้อยละในเกณฑ์ + กราฟเส้นในบทที่ 4)
- ภาพหลักฐานการทดสอบในบทที่ 4 พร้อมคำบรรยาย เลขภาพอัตโนมัติ ครอบตัด หมุน และเลือกขนาดภาพในเล่ม (เล็ก/กลาง/ใหญ่)

ข้อมูลเดิมที่นักเรียนกรอกไว้ในเว็บเวอร์ชันแรก (เก็บในเบราว์เซอร์) นำเข้าได้ด้วยปุ่ม "สร้างจากข้อมูลเดิมในเครื่องนี้" หรือไฟล์สำรอง .json

## Deploy บน Railway

1. ใน Railway project เดิม กด **+ New → Database → PostgreSQL**
2. เปิด service ของเว็บ → **Variables** แล้วเพิ่ม
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (เลือกจากรายการ Reference)
   - `TEACHER_INVITE_CODE` = รหัสลับที่ครูใช้สร้างบัญชีครู (ตั้งเอง เช่น วลีที่เดายาก)
3. Push โค้ดนี้ขึ้น GitHub แล้ว Railway จะ build จาก `Dockerfile` อัตโนมัติ (ติดตั้ง LibreOffice และฟอนต์ให้)
4. เปิดเว็บ → แท็บ **ครู** → สร้างบัญชีครูด้วยรหัสเชิญ → สร้างห้อง → ส่งรหัสห้องให้นักเรียน

ตารางฐานข้อมูลสร้างเองตอนเริ่มเซิร์ฟเวอร์ ภาพถ่ายเก็บในฐานข้อมูล จึงไม่ต้องเพิ่ม Volume ในเวอร์ชันนี้

## รันบนเครื่อง

```bash
# ต้องมี Node 20+, PostgreSQL, LibreOffice (soffice) และ poppler-utils (pdftoppm, pdftotext)
npm ci
DATABASE_URL=postgres://user:pass@localhost:5432/projectelec TEACHER_INVITE_CODE=ลับมาก npm start
```

```

server/db.js           PostgreSQL + migrations
server/auth.js         รหัสผ่าน (scrypt) และ session cookie
server/docgen.js       DOCX → PDF (LibreOffice) → ภาพหน้า A4 (poppler)
public/shared/engine.js  ตัวสร้างเนื้อหาเอกสารตามคู่มือ ใช้ร่วมกันทั้งมือถือและเซิร์ฟเวอร์
public/app.js          หน้าจอมือถือ คพ.01 แบบตอบคำถาม การซิงก์ หน้าครู
public/p1.js           ส่งงาน/ความเห็น/แบบ คพ.03 05 07/บันทึกคะแนนและผลทดลอง/ครอบตัดภาพ
public/editors.js      ตัวแก้ไขละเอียดของแต่ละบท
fonts/                 TH SarabunPSK (ฟอนต์แห่งชาติ SIPA) และ Sarabun สำหรับกราฟ
```
